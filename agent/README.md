# agent/ — Karar destek ajanı (planlanan)

Henüz kod yok.

**Planlanan:**
- LLM tabanlı ReAct (düşün → araç çağır → gözlemle) ajanı
- Araçlar: raf durumu, eksik ürün listesi, olay geçmişi, simüle stok sorgusu
- Çıktı: personel için önceliklendirilmiş, gerekçeli yeniden doldurma listesi
- Kural tabanlı temel yöntem: karşılaştırma ölçütü ve LLM'e erişilemediğinde yedek
- Değerlendirme: hazır senaryolarda beklenen öncelik sıralamasıyla karşılaştırma
